# ⚔️ Mitologia Grega - React App

Este é um projeto web desenvolvido em **React**, com foco em **personagens da mitologia grega**. A aplicação permite **explorar personagens**.

---

## 🌐 Demonstração

> O site pode ser acessado via GitHub Pages:  
[https://MatheusCEvangelista.github.io/mitologia-grega](https://MatheusCEvangelista.github.io/mitologia-grega)

---

## 🔥 Funcionalidades

- 👁️ Visualização de personagens da mitologia grega
- 🚀 Deploy via GitHub Pages

---

## 🛠️ Tecnologias Utilizadas

- React 19
- Axios
- React Scripts
- GitHub Pages

---

## 📦 Instalação

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/mitologia-grega.git

# Acesse a pasta
cd mitologia-grega

# Instale as dependências
npm install

# Rode a aplicação localmente
npm start

# Rode o JSON
json-server --watch db.json --port 3001
